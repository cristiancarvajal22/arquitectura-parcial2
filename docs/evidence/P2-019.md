# Coherencia / Coherence

`node --test tests/unit/coherence.test.cjs`: 6 casos locales. Invalidación por
rango físico para L1I, L1D y cuatro líneas L2; tag = floor(PA/8). Preserva
vecinos y orden de FIFO restante. Los alias virtuales convergen en el mismo PA.
E/S 224..239 evita caché; 240..255 se rechaza. Cambiar memoria cancela fills L1I
pendientes mediante generación, incluso si la línea residente es distinta.

Si una copia afectada es dirty, devuelve `needs-writeback` con sus bytes y no
modifica nada. El coordinador debe resolver el writeback según #3 y volver a
solicitar invalidación; no se inventa una política ni se descartan bytes sucios.
El coordinador debe confirmar memoria e invalidación en una sola transacción.

Pendiente: política #3, escritores reales L1D/L2/RAM/Swap, Dirty/Reference y
prueba end-to-end de fetch tras edición. No desplegado ni tarea cerrada.

English: physical-range invalidation preserves neighboring lines and refuses
to discard dirty copies. Six tests cover aliasing, frame replacement, pending
fills and I/O routing. Write policy and system integration remain pending.
