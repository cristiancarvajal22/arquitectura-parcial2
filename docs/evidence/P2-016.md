# L1I / Instruction cache

Una línea física de 8 bytes. `lookup` solo acepta fetch; datos hacen bypass,
E/S no es ejecutable. MMU debe traducir cada byte antes de consultar L1I.
Un miss devuelve una solicitud explícita a L2; `fill` valida dirección, tamaño,
bytes y generación. Invalidar también cancela respuestas pendientes.

Prueba: `node --test tests/unit/l1i.test.cjs` (5 casos). Incluye frío/hit,
salto, cruce de página con marcos no contiguos, invalidación y respuesta obsoleta.
La respuesta L2 es un doble: falta conectar L2 real (#18), fetch (#5),
eventos/contadores y coordinar el contrato #3. No hay ejecución en Sheets.

English: one physical eight-byte instruction line, explicit L2 miss requests,
generation-checked fills and invalidation. Five local tests use an L2 response
double; real L2, CPU fetch and Sheets integration remain pending.
