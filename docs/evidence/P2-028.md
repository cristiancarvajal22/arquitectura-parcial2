# Demo aritmética / Arithmetic demo

AX acumula; BX es el siguiente sumando; CX guarda el límite; DX cuenta vueltas.
Cinco vueltas suman 1+2+3+4+5=15. Al terminar: AX=15, BX=6, CX=DX=5,
VA 300=15, PC=40 (HALT). CMP final: ZF=1, CF=SF=0. Son 31 instrucciones.
La variante cambia solo MOV CX,5 por MOV CX,6: suma 21 en 36 instrucciones.
`programs/arithmetic.expected.json` registra el oráculo manual tras cada CMP.
