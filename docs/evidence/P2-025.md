# P2-025 · Analizador ASM

`node --test tests/unit/assembler.test.cjs`: 34 pruebas aprobadas.
`AsmParser.assemble(text, origin=0)` reconoce la ISA de #2 y devuelve bytes,
instrucciones con direcciones/líneas y etiquetas. No escribe RAM ni Sheets.
Resuelve etiquetas hacia adelante y atrás, sin exigir alineación a cuatro.
Los saltos solo pueden apuntar al inicio de una instrucción del programa.

Registros/instrucciones/etiquetas no distinguen mayúsculas. Números decimales,
hex `0xFF` o `0FFh`; comentarios con `;`; operandos separados por comas.
Se admiten etiquetas antes de instrucciones o solas. No se implementan directivas
de datos ni un cargador. IN exige rd,[KBD]; OUT exige [LCD],rs.
LOAD permite inspeccionar KBD; STORE KBD y direcciones reservadas se rechazan.

Errores incluyen línea y motivo. Ante cualquier error, bytes e instrucciones
quedan vacíos: no se entrega un programa parcial al cargador. Origen y longitud
se limitan al área 0..479. El ejemplo oficial produce exactamente sus 20 bytes.
Pruebas cubren todas las variantes, etiquetas duplicadas/ausentes, registros,
overflow, límites, saltos inválidos, sintaxis de E/S y comentarios.

Pendiente: conectar editor, presentación de errores y cargador transaccional
en Sheets. No se cargó ni ejecutó ningún programa en la hoja. Revisión pendiente.

English: two-pass assembler with line errors and all-or-nothing output; 34 tests
